# Отчёт по лабораторной работе №3
## Тема: Создание Multi-Agent системы с координацией задач

## 1. Цель работы
Целью лабораторной работы было изучение подходов к построению многоагентных систем и реализация собственного multi-agent решения на базе CrewAI с координацией задач, обменом сообщениями и адаптацией под предметную область дипломного проекта.

## 2. Основные концепции CrewAI
- `Agent` описывает роль, цель, backstory и специализацию исполнителя.
- `Task` задаёт отдельную работу, ожидаемый результат и исполнителя.
- `Crew` объединяет агентов и задачи в общий процесс выполнения.
- `Process.sequential` позволяет организовать последовательную передачу результата между агентами.
- Делегирование и разделение ролей упрощают построение сложных пайплайнов анализа.

## 3. Реализованная архитектура
Система состоит из трёх специализированных агентов:
- `ResearcherAgent` собирает контекст по проблеме, использует поиск и семантическую память.
- `AnalystAgent` преобразует найденные данные в прикладной производственный анализ.
- `WriterAgent` оформляет финальный отчёт для пользователя и демонстрации.

Для координации реализована шина сообщений `message_bus.py`, через которую агенты явно передают результаты друг другу.

## 4. Адаптация под специальность
Предметная область проекта: информационная система контроля дефектов закупорки молочной тары на производстве. Multi-agent система решает кейсы, связанные с неполной закупоркой, смещением крышки, протечкой и анализом причин брака.

## 5. Ход выполнения
1. Изучен базовый паттерн `Agent -> Task -> Crew`.
2. Реализованы три специализированных агента.
3. Создан orchestrator `MultiAgentResearchCrew`.
4. Настроена передача сообщений через `InMemoryMessageBus`.
5. Описаны задачи crew в `task_definitions.py`.
6. Добавлены тесты и демонстрационный ноутбук.

## 6. Тестирование
Проверяются:
- доставка сообщений через message bus;
- корректность описания задач;
- сквозной запуск всей multi-agent системы;
- сериализация результатов crew для notebook-демо.

## 7. Вывод
В ходе лабораторной работы были изучены принципы построения multi-agent систем и реализована практическая архитектура с явной координацией задач. В дальнейшем систему можно расширить асинхронным выполнением, подключением дополнительных CrewAI Tools и более сложной маршрутизацией сообщений.
