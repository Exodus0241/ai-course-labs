## 1. Теоретическое введение

### 1.1 Импульсные нейронные сети (SNN)

Импульсные нейронные сети (Spiking Neural Networks, SNN) — третье поколение нейронных сетей, вдохновлённое биологическими принципами работы мозга. В отличие от традиционных ANN, передающих вещественные активации, SNN передают информацию через **спайки** — дискретные события во времени.

**Ключевые свойства SNN:**
- **Событийная обработка:** нейрон генерирует выход только при превышении порога
- **Разреженность:** в любой момент времени активно лишь малое число нейронов
- **Временна́я динамика:** нейрон «помнит» историю через мембранный потенциал
- **Энергоэффективность:** вычисления только при наличии спайков

### 1.2 Модель LIF (Leaky Integrate-and-Fire)

Наиболее распространённая модель нейрона в SNN:

$$\tau_m \frac{dV}{dt} = -(V - V_{rest}) + R \cdot I(t)$$

В дискретном виде (метод Эйлера):

$$V[t] = \beta \cdot V[t-1] + I[t]$$

$$\text{если } V[t] \geq \theta \Rightarrow \text{спайк}, \quad V[t] \leftarrow 0$$

где:
- $V[t]$ — мембранный потенциал на шаге $t$
- $\beta \in (0, 1]$ — коэффициент утечки (decay factor)
- $I[t]$ — входной ток
- $\theta$ — порог срабатывания

### 1.3 Rate Coding

Для кодирования непрерывных входных значений в спайки используется **rate coding**: значение $x \in [0, 1]$ интерпретируется как вероятность спайка на каждом временном шаге:

$$S[t] = \begin{cases} 1, & \text{если } \text{rand}() < x \\ 0, & \text{иначе} \end{cases}$$

Это позволяет адаптировать аналоговые сигналы датчиков для обработки в SNN.

### 1.4 Обучение через суррогатный градиент

Спайковая функция недифференцируема, поэтому snntorch использует **суррогатный градиент** (fast sigmoid):

$$\frac{\partial S}{\partial V} \approx \frac{1}{(k|V - \theta| + 1)^2}$$

Это позволяет применять стандартный алгоритм обратного распространения ошибки.

## 2. Описание задачи

### 2.1 Контекст дипломной работы

**Тема:** Информационная система контроля дефектов закупорки молочной тары на производстве.

На производственных линиях розлива молочной продукции возникают дефекты закупорки, приводящие к порче продукта, отзывам партий и финансовым потерям. Датчики давления и вибрации фиксируют временны́е ряды сигналов, по которым можно автоматически определять тип дефекта.

### 2.2 Классификация дефектов

| ID | Класс | Описание | Характеристика сигнала |
|----|-------|----------|------------------------|
| 0 | Норма | Герметичная закупорка | Стабильный низкий уровень |
| 1 | Дефект давления | Неплотная крышка | Импульсный скачок |
| 2 | Вибрационный дефект | Крышка дребезжит | Синусоидальный паттерн |
| 3 | Разгерметизация | Утечка продукта | Нарастающий тренд |

### 2.3 Почему SNN для данной задачи?

SNN особенно выгодны для edge-устройств на производственной линии:

- **Событийная обработка:** аномалии в сигнале датчиков — редкие события → разреженные спайки → низкое энергопотребление
- **Временна́я память:** LIF-нейрон естественно учитывает историю сигнала без явных рекуррентных соединений
- **Совместимость с нейроморфным железом:** Intel Loihi, IBM TrueNorth — на порядки эффективнее GPU/CPU при работе со SNN

### 3.2 Архитектура SNN-классификатора

```
Вход: сигнал датчика [batch, 64]
    ↓ Rate Encoding (25 временных шагов)
FC(64→128) → LIF₁(β=0.9, learnable) → [batch, 128] спайки
    ↓
FC(128→64) → LIF₂(β=0.9, learnable) → [batch, 64] спайки
    ↓
FC(64→4)   → LIF₃(β=0.9, learnable) → [batch, 4] спайки
    ↓
Σ по времени → spike_counts [batch, 4]
    ↓ CrossEntropyLoss
Предсказанный класс
```

**Параметры модели:** ~26 000 (сопоставимо с ANN)

### 3.3 Особенности реализации для Apple Silicon

```python
def get_device() -> torch.device:
    if torch.backends.mps.is_available():
        try:
            _test = torch.zeros(1).to("mps")
            return torch.device("mps")
        except Exception:
            pass
    return torch.device("cpu")
```

MPS-backend PyTorch поддерживает большинство операций snntorch, но для некоторых суррогатных градиентов требуется CPU fallback.

### 4.2 Формулы генерации сигналов

- **Норма:** $s[t] = 0.25 + \varepsilon$, где $\varepsilon \sim \mathcal{N}(0, 0.1)$
- **Давление:** $s[t] = \mathbf{1}_{[t_1, t_2]} \cdot A + \varepsilon$, $A \sim U(1.5, 2.5)$
- **Вибрация:** $s[t] = 0.7 \sin(2\pi f t) + 0.5 + \varepsilon$, $f \sim U(4, 8)$
- **Утечка:** $s[t] = \text{linspace}(0.1, A)$, $A \sim U(1.5, 2.2)$

## 5. Результаты обучения

### 5.1 SNN — метрики

| Метрика | Значение |
|---------|----------|
| Точность (test) | ~0.87–0.93 |

### 5.2 Сравнение SNN vs ANN

| Метрика | SNN | ANN | Победитель |
|---------|-----|-----|------------|
| Точность | ~0.90 | ~0.95 | ANN |
| F1-macro | ~0.89 | ~0.94 | ANN |
| Параметров | ~26K | ~26K | Равно |
| SynOps / MACs | ~800 | ~21K | **SNN** (в 26x меньше) |
| Инференс | сопоставимо | сопоставимо | — |
| Время обучения | выше | ниже | ANN |

### 5.3 Анализ энергоэффективности

Метрика **SynOps** (Synaptic Operations) отражает количество активных вычислений в SNN:
- В ANN каждое соединение активно на каждом проходе → MACs ≈ 21 000/образец
- В SNN вычисление происходит только при наличии спайка → SynOps ≈ 800/образец

**Вывод:** SNN потенциально в 20-30x энергоэффективнее ANN при развёртывании на нейроморфном железе.

## 6. Выводы

1. **LIF-нейрон** успешно реализован на snntorch и демонстрирует корректную нейронную динамику: интеграцию тока, утечку потенциала, генерацию спайков и сброс.

2. **SNN-классификатор** достигает точности ~90% на синтетическом датасете дефектов закупорки, что достаточно для прототипирования системы контроля.

3. **ANN** превосходит SNN по точности на данной задаче (~5%), однако SNN даёт принципиально меньше вычислительных операций (~26x).

4. **Rate coding** эффективно кодирует аналоговые сигналы датчиков в спайковые последовательности, хотя требует дополнительных временны́х шагов.

5. **Применимость в дипломной работе:** SNN перспективны для встраиваемых систем контроля качества (edge AI), где критичны энергопотребление и задержка, а не только точность.

Можно поиграть с параметрами и пожертвовав немного точностью классификации можно прийти к равнозначным по производительности метрикам.
Но конкретно на моем железе при примерно равном количестве параметров, в скорости и обучения и инференса выигрывает ANN (хоть и в SNN используется меньше операций)
Эх, если бы у нас был свой нейроморфный чип
