# Отчёт по лабораторной работе №4
## Тема: Workflow Automation с интеграцией AI

## Статус
Подготовлены части 1-4 в базовом виде: окружение, workflow exports, Python-клиент для тестирования и документация.

## Выполнено
- Развёрнута структура `week4/` и Docker-конфигурация для `n8n + PostgreSQL`.
- Создан `basic_workflow.json` для обработки заявок с YandexGPT-классификацией, ветвлением и email-уведомлением.
- Создан `specialty_workflow.json`, адаптированный под тему диплома о дефектах закупорки молочной тары.
- Реализован Python-клиент `WorkflowClient` для тестовых вызовов webhook.
- Добавлены тесты на JSON-экспорты и клиентскую логику.

## Базовый сценарий
1. Вебхук получает заявку.
2. YandexGPT классифицирует обращение.
3. Узел `IF Tech Support` проверяет категорию.
4. При техподдержке отправляется email менеджеру.
5. Заявка записывается в таблицу.

## Специализированный сценарий
1. Вебхук получает сообщение о дефекте закупорки.
2. YandexGPT возвращает JSON с серьёзностью, причиной и рекомендацией.
3. Узел `IF Critical` проверяет критичность.
4. При критическом инциденте технолог получает письмо.
5. Результат записывается в таблицу дефектов.

## Следующий шаг
Импортировать workflow JSON-файлы в n8n, настроить SMTP и Google Sheets credentials, затем проверить выполнение тестовыми webhook-запросами.
