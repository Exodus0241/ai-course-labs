## 3. Ход работы
### 3.1. Архитектура агента
Агент построен по модульной архитектуре. В `agent_core.py` находится сборка всех компонентов: LLM, инструменты, краткосрочная память, семантическая память и guardrails. Перед обработкой запроса выполняется валидация входных данных. Затем агент получает контекст из оперативной памяти и релевантные записи из ChromaDB, после чего формирует ответ и сохраняет новые данные в память.

Схема взаимодействия:
1. Пользователь отправляет запрос.
2. `InputValidator` проверяет длину и опасные шаблоны.
3. `WorkingMemory` возвращает недавний контекст диалога.
4. `SemanticMemory` находит похожие записи в ChromaDB.
5. LangChain-агент выбирает подходящий инструмент или отвечает напрямую.
6. Новый запрос и ответ сохраняются в обе подсистемы памяти.

### 3.2. Реализованные инструменты

### 3.3. Кастомный инструмент
В качестве профильного инструмента был разработан `custom_tool`, ориентированный на тему дипломной работы: "Информационная система контроля дефектов закупорки молочной тары на производстве". Инструмент принимает тип дефекта, этап производства и наблюдаемые признаки, после чего формирует вероятные причины, контрольные параметры, источники данных, корректирующие действия и KPI для будущей информационной системы.

Листинг кода см. в файле `week2/src/tools/custom_tool.py`.

Пример использования:
```python
tool._run(
    defect_type="неполная закупорка",
    production_stage="укупорочный модуль",
    symptoms="смещение крышки и протечка части продукции"
)
```

### 3.4. Тестирование
Для проекта написаны unit-тесты:
- проверка блокировки опасных запросов;
- проверка безопасного калькулятора;
- проверка кастомного инструмента;
- проверка поиска по семантической памяти;
- проверка ответа агента при срабатывании guardrails.

### 3.5. Интеграция с дипломом
Разработанный агент может использоваться как вспомогательный модуль дипломного проекта по контролю дефектов закупорки молочной тары. Связка из поискового инструмента, вычислений, памяти и специализированного анализа дефектов позволяет собирать технологические знания, быстро разбирать производственные инциденты и проектировать логику будущей информационной системы.

## 5. Выводы
В ходе лабораторной работы были изучены основы построения AI-агентов на базе LangChain, создание кастомных инструментов, организация краткосрочной и долгосрочной памяти, а также реализация базовых guardrails.
